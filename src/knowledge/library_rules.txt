# 一、系统整体架构（线上版）
## 1.1 部署架构
线上图书管理系统采用B/S架构，核心分层：
- 前端层：Web端（Vue3+Element Plus）、移动端（微信小程序/APP）
- 接口层：RESTful API（基于FastAPI/Spring Boot），统一前缀：/api/v1/library
- 数据层：MySQL主从架构（读写分离）+ Redis缓存（热门图书/读者会话）
- 存储层：OSS对象存储（图书封面/附件）
- 权限层：JWT令牌认证 + RBAC角色权限控制

## 1.2 核心角色及CRUD权限
| 角色         | 图书模块       | 读者模块       | 借阅模块       | 分类/库位模块 | 系统配置模块 |
|--------------|----------------|----------------|----------------|---------------|--------------|
| 超级管理员   | 全部CRUD       | 全部CRUD       | 全部CRUD       | 全部CRUD      | 全部CRUD     |
| 管理员       | 全部CRUD       | 查/改/禁用     | 全部CRUD       | 全部CRUD      | 查           |
| 操作员       | 查/新增/改     | 查/改          | 新增/查/完结   | 查/新增/改    | -            |
| 普通读者     | 仅查           | 查/改个人信息  | 查/申请续借    | 仅查          | -            |
| VIP读者      | 仅查（含预约） | 查/改个人信息  | 查/申请续借/预约 | 仅查          | -            |

# 二、核心模块CRUD全规则（管理员端）
## 2.1 图书模块（核心CRUD）
### 2.1.1 新增图书（CREATE）
#### 接口信息
- 接口地址：/api/v1/library/books
- 请求方式：POST
- 请求头：Authorization: Bearer {JWT令牌}
- 内容类型：application/json

#### 必传参数（非空校验）
| 参数名         | 类型     | 示例值                          | 校验规则                                                                 |
|----------------|----------|---------------------------------|--------------------------------------------------------------------------|
| isbn           | string   | 9787508095227                   | 唯一，格式校验（13位数字），重复则返回400错误："ISBN已存在"               |
| book_name      | string   | 三体（全集）                    | 长度1-100字符，禁止特殊字符（<>/\等）                                   |
| author         | string   | 刘慈欣                          | 长度1-50字符，禁止特殊字符                                               |
| publisher      | string   | 重庆出版社                      | 长度1-50字符，禁止特殊字符                                               |
| publish_date   | string   | 2018-05-01                      | 日期格式（YYYY-MM-DD），不能晚于当前日期                                 |
| category_id    | int      | 1001                            | 必须存在于分类表中，否则返回400："分类ID不存在"                          |
| stock          | int      | 10                              | ≥0，默认值1，库存为0则状态自动设为"缺货"                                |
| location       | string   | 科幻区-02架-05层                | 符合库位编码规则（区域+架号+层号），否则返回400："库位格式错误"          |
| status         | string   | in_library                      | 枚举值：in_library/borrowed/repair/lost/discarded，默认in_library        |

#### 可选参数
| 参数名         | 类型     | 示例值                          | 说明                                                                     |
|----------------|----------|---------------------------------|--------------------------------------------------------------------------|
| price          | decimal  | 88.00                           | 保留2位小数，≥0                                                          |
| cover_url      | string   | https://oss.xxx.com/cover/1.jpg | OSS地址，格式校验（http/https开头）                                      |
| tags           | array    | ["科幻","热门","获奖"]          | 数组格式，每个标签1-20字符，最多10个标签                                |
| remarks        | string   | 2023年印刷版                    | 长度0-500字符                                                           |
| storage_date   | string   | 2026-01-10                      | 入库日期，默认当前日期                                                   |

#### 操作流程
1. 操作员/管理员填写表单，前端做参数校验（格式/非空）；
2. 前端调用新增接口，携带JWT令牌；
3. 后端校验：
   - 权限校验（是否有新增权限）；
   - 参数校验（ISBN唯一性、分类ID存在性、格式等）；
   - 库存与状态联动（stock=0则status=out_of_stock）；
4. 校验通过：写入数据库，返回201 Created + 图书ID；
5. 校验失败：返回400 Bad Request + 具体错误信息；
6. 日志记录：操作人、操作时间、新增图书ISBN/名称、IP地址。

#### 批量新增
- 接口地址：/api/v1/library/books/batch
- 请求方式：POST
- 支持Excel导入/JSON数组（最多500条/次）；
- 失败处理：批量新增时部分失败则回滚全部，返回失败明细（如第3条ISBN重复）。

### 2.1.2 查询图书（READ）
#### 基础查询（单本/列表）
- 接口地址：/api/v1/library/books
- 请求方式：GET
- 支持参数：
  | 参数名         | 类型     | 示例值                          | 说明                                                                     |
  |----------------|----------|---------------------------------|--------------------------------------------------------------------------|
  | id             | int      | 10001                           | 图书ID，精准查询单本                                                     |
  | isbn           | string   | 9787508095227                   | ISBN，精准查询单本                                                       |
  | book_name      | string   | 三体                            | 书名模糊查询（包含关键词）                                               |
  | author         | string   | 刘慈欣                          | 作者模糊查询                                                             |
  | category_id    | int      | 1001                            | 分类ID，查询该分类下所有图书                                             |
  | status         | string   | in_library                      | 状态筛选                                                                 |
  | page           | int      | 1                               | 页码，默认1                                                              |
  | page_size      | int      | 20                              | 每页条数，默认20，最大50                                                 |
  | sort           | string   | publish_date_desc               | 排序：publish_date_desc（出版日期降序）/stock_asc（库存升序）等           |

#### 高级查询
- 接口地址：/api/v1/library/books/advanced
- 请求方式：POST
- 支持多条件组合筛选（如：分类ID=1001 + 出版日期≥2020-01-01 + 库存≥5）；
- 支持导出结果（Excel/PDF），接口：/api/v1/library/books/export。

#### 缓存规则
- 热门图书（近7天借阅量≥10）缓存至Redis，有效期1小时；
- 单本图书查询优先读缓存，缓存失效则查数据库并更新缓存；
- 新增/修改/删除图书后，自动清空该图书/分类的缓存。

### 2.1.3 修改图书（UPDATE）
#### 接口信息
- 接口地址：/api/v1/library/books/{book_id}
- 请求方式：PUT
- 请求头：Authorization: Bearer {JWT令牌}
- 内容类型：application/json

#### 可修改参数（区分权限）
| 参数名         | 操作员权限 | 管理员权限 | 说明                                                                     |
|----------------|------------|------------|--------------------------------------------------------------------------|
| book_name      | 不可改     | 可改       | 仅管理员可修改，修改后同步更新缓存                                       |
| author         | 不可改     | 可改       | 仅管理员可修改                                                           |
| publisher      | 不可改     | 可改       | 仅管理员可修改                                                           |
| publish_date   | 不可改     | 可改       | 仅管理员可修改                                                           |
| category_id    | 可改       | 可改       | 修改后同步更新分类统计                                                   |
| stock          | 可改       | 可改       | 库存变更需记录操作日志（如：从10改为8，备注：盘点减少2本）               |
| location       | 可改       | 可改       | 库位调整实时生效                                                         |
| status         | 可改       | 可改       | 状态变更需校验（如：lost状态需填写丢失原因）                             |
| price          | 可改       | 可改       | 价格调整仅影响未借出图书                                                 |
| cover_url      | 可改       | 可改       | 支持更换封面图片                                                         |
| tags           | 可改       | 可改       | 支持新增/删除标签                                                       |
| remarks        | 可改       | 可改       | 无限制修改                                                               |

#### 操作流程
1. 前端查询图书详情，加载当前参数；
2. 操作员/管理员修改可编辑字段，前端校验；
3. 后端校验：
   - 权限校验（是否允许修改该字段）；
   - 图书状态校验（如：discarded状态图书不可修改除备注外的字段）；
   - 库存与状态联动（stock>0时，status不能为out_of_stock）；
4. 校验通过：更新数据库，返回200 OK + 更新后数据；
5. 校验失败：返回400 Bad Request + 错误信息；
6. 缓存处理：删除该图书的Redis缓存；
7. 日志记录：操作人、修改前后字段对比、操作时间。

### 2.1.4 删除图书（DELETE）
#### 接口信息
- 接口地址：/api/v1/library/books/{book_id}
- 请求方式：DELETE
- 请求头：Authorization: Bearer {JWT令牌}

#### 权限控制
- 仅管理员/超级管理员可删除；
- 操作员无删除权限，仅可申请删除（需管理员审批）。

#### 删除规则（软删除为主）
| 删除类型       | 适用场景                          | 操作逻辑                                                                 |
|----------------|-----------------------------------|--------------------------------------------------------------------------|
| 软删除（默认） | 图书下架/报废/长期无库存          | 仅修改status为discarded，保留所有数据，可恢复                           |
| 硬删除         | 重复录入/错误录入（未产生借阅）| 物理删除数据库记录，需超级管理员审批，删除前自动备份                     |

#### 操作流程
1. 管理员发起删除请求，选择删除类型；
2. 后端校验：
   - 权限校验（超级管理员可硬删除，管理员仅可软删除）；
   - 图书状态校验（有未归还借阅记录的图书不可删除，需先完结借阅）；
3. 软删除：更新status=discarded，返回200 OK；
4. 硬删除：审批通过后物理删除，返回204 No Content；
5. 缓存处理：删除该图书所有缓存；
6. 日志记录：操作人、删除类型、图书ID/ISBN、操作时间、审批人（硬删除）。

## 2.2 读者模块CRUD
### 2.2.1 新增读者（CREATE）
- 接口地址：/api/v1/library/readers
- 请求方式：POST
- 必传参数：id_card（身份证/学号，唯一）、reader_name、phone、reader_type；
- 规则：
  1. 身份证/学号唯一性校验，重复则返回400；
  2. 手机号格式校验（11位数字）；
  3. 读者类型默认normal，可指定student/teacher/vip；
  4. 新增后自动生成读者证号（规则：馆代码+年份+6位序号，如LIB2026000001）。

### 2.2.2 查询读者（READ）
- 接口地址：/api/v1/library/readers
- 请求方式：GET
- 支持参数：reader_id、id_card、reader_name、phone、reader_type、page、page_size；
- 高级查询：可按借阅状态（有逾期/无逾期）、借阅数量筛选。

### 2.2.3 修改读者（UPDATE）
- 接口地址：/api/v1/library/readers/{reader_id}
- 请求方式：PUT
- 可修改参数：phone、email、unit、reader_type、remarks；
- 规则：
  1. id_card不可修改（唯一标识）；
  2. 修改reader_type需同步更新借阅权限（如普通读者改VIP，借阅数量从5增至15）；
  3. 读者本人仅可修改phone/email，管理员可修改所有字段。

### 2.2.4 禁用读者（替代删除）
- 接口地址：/api/v1/library/readers/{reader_id}/disable
- 请求方式：PUT
- 规则：
  1. 软禁用：修改reader_type=blacklist，保留数据，可恢复；
  2. 禁用后立即冻结所有借阅权限，有未归还图书的需先提醒归还；
  3. 仅管理员/超级管理员可禁用/恢复。

## 2.3 借阅模块CRUD
### 2.3.1 新增借阅（CREATE）
- 接口地址：/api/v1/library/borrows
- 请求方式：POST
- 必传参数：book_id、reader_id；
- 自动计算：
  1. borrow_time=当前时间；
  2. due_time=borrow_time + 读者类型对应时长（如普通读者+30天）；
  3. renew_times=0；
- 联动操作：
  1. 图书stock-1，status=borrowed；
  2. 校验读者借阅数量（未超上限）、图书状态（可借）。

### 2.3.2 查询借阅（READ）
- 接口地址：/api/v1/library/borrows
- 请求方式：GET
- 支持参数：borrow_id、book_id、reader_id、status（borrowed/returned/overdue）、borrow_time_start/end；
- 读者端仅可查询本人借阅记录，管理员可查询所有。

### 2.3.3 修改借阅（UPDATE）
- 接口地址：/api/v1/library/borrows/{borrow_id}
- 请求方式：PUT
- 仅支持续借操作（修改due_time、renew_times）；
- 规则：
  1. 续借次数未超上限；
  2. 图书未逾期；
  3. 续借后due_time延长对应时长（如普通读者+30天）。

### 2.3.4 完结借阅（DELETE替代）
- 接口地址：/api/v1/library/borrows/{borrow_id}/return
- 请求方式：PUT
- 操作逻辑：
  1. 填写return_time=当前时间；
  2. 计算逾期时长及费用（如有）；
  3. 更新borrow_status=returned；
  4. 联动更新图书stock+1，status=in_library；
  5. 逾期费未缴清则标记，限制该读者后续借阅。

## 2.4 分类/库位模块CRUD
### 2.4.1 分类模块
- 新增：/api/v1/library/categories（POST），支持多级分类（parent_id）；
- 查询：/api/v1/library/categories（GET），支持树形结构返回；
- 修改：/api/v1/library/categories/{category_id}（PUT），仅可修改名称/排序；
- 删除：/api/v1/library/categories/{category_id}（DELETE），有图书关联的分类不可删除（需先迁移图书）。

### 2.4.2 库位模块
- 新增：/api/v1/library/locations（POST），需符合编码规则；
- 查询：/api/v1/library/locations（GET），支持按区域筛选；
- 修改：/api/v1/library/locations/{location_id}（PUT），可修改名称/编码；
- 删除：/api/v1/library/locations/{location_id}（DELETE），有图书关联的库位不可删除。

# 三、读者端CRUD规则（仅查询+部分操作）
## 3.1 可执行操作
1. 图书查询：仅可查基础信息（ISBN/书名/作者/状态/库位），不可查库存/采购价；
2. 个人信息：查询+修改手机号/邮箱/密码；
3. 借阅记录：查询本人借阅记录，申请续借/预约；
4. 图书预约：仅可预约已借出的图书，预约后系统锁定该图书（归还后优先分配）。

## 3.2 权限限制
1. 无新增/删除权限；
2. 不可修改图书/其他读者信息；
3. 不可查看其他读者借阅记录；
4. 逾期未归还图书则限制部分查询（如预约功能）。

# 四、接口调用规范（前后端交互）
## 4.1 通用响应格式
```json
{
  "code": 200, // 200成功，400参数错误，401未授权，403权限不足，404不存在，500服务器错误
  "msg": "操作成功", // 错误时返回具体原因
  "data": {}, // 成功时返回数据，失败时可为null
  "timestamp": 1710000000000 // 时间戳
}
